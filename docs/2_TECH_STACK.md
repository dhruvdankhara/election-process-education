### 1. Frontend + Backend (Core)

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **UI:** shadcn/ui + Tailwind CSS
- **Forms & Validation:** React Hook Form + Zod
- **Date Handling:** date-fns

---

## 2. Authentication & User Management

- **Primary:** NextAuth.js (Auth.js)
- **Provider:** Google OAuth
- **Session Storage:** Firestore / JWT

---

## 3. Database & Storage

- **Database:** Google Cloud Firestore
- **File Storage:** Google Cloud Storage

---

## 4. AI & Intelligence Layer (Core of your product)

- **LLM:** Google Vertex AI
- **Text-to-Speech:** Google Cloud Text-to-Speech
- **Speech-to-Text (ADD):** Google Cloud Speech-to-Text
- **Translation:** Google Cloud Translation API

## 5. API Layer & Documentation

- **API Style:** REST + Server Actions
- **Docs:** OpenAPI (Swagger UI)

---

## 6. Testing & Code Quality

- **Unit Testing:** Jest
- **E2E Testing:** Playwright
- **Linting:** ESLint + Prettier

## 7. DevOps & Deployment

- **Hosting:** Google Cloud Run
